📝 Program Description

The Word Counter program accepts a sentence from the user and then displays:

· The number of words in the sentence.
· The number of characters (excluding spaces).
· The longest word (if multiple words have the same length, the first one encountered is shown).

The program includes input validation: if the user enters nothing (or only spaces), it prints an error message and exits gracefully.

🚀 How to Run

1. Ensure you have Python 3 installed on your computer.
2. Navigate to the folder containing word_counter.py.
3. Run the program with:
   ```bash
   python word_counter.py
   ```
4. When prompted, enter any sentence (e.g., "Hello world!") and press Enter.
5. The results will be displayed immediately.

📋 Example

```
Enter a sentence: Python programming is fun!

Number of words: 4
Number of characters (excluding spaces): 22
Longest word: programming
```

⚙️ Requirements

· Python 3.x
· No external libraries are needed – only standard Python functions.
